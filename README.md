# 42-piscine-pedago-data-science
"Piscine" (Piscina) de Ciencia de Datos (Data Science) en la metodología de la famosa red de escuelas de programación 42 Network. Una Piscine es un formato de aprendizaje intensivo y colaborativo, muy conocido en esta red, donde no hay profesores y los estudiantes avanzan resolviendo módulos prácticos y evaluándose entre sí (peer-evaluations).
